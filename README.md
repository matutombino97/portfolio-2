# Portfolio B2B - Soluciones Digitales

Este repositorio contiene una versión de mi portfolio profesional diseñada específicamente para **clientes comerciales y dueños de negocios** (B2B).

A diferencia de mi portfolio creativo (orientado al mundo IT), este proyecto se centra en la **conversión, la claridad y la velocidad**, utilizando un diseño minimalista estilo "Bento Grid" para comunicar valor de forma inmediata.

## Objetivo del Proyecto

Demostrar cómo una presencia digital estratégica puede ayudar a negocios locales (Pymes, consultorios, gastronomía) a digitalizarse sin fricción.

## Tecnologías Utilizadas

El foco fue la performance y la accesibilidad universal (SEO), evitando la sobrecarga de frameworks innecesarios para una Landing Page.

* **HTML5 Semántico:** Estructura limpia y optimizada para buscadores.
* **CSS3 Moderno:** Uso de Grid y Flexbox para el layout "Bento". Variables CSS para consistencia.
* **JavaScript (Vanilla):** Lógica ligera para el carrusel de proyectos y micro-interacciones.
* **Formspree:** Integración de formulario de contacto serverless.

## Características Clave

* **Diseño Bento Grid:** Organización modular de la información (inspirado en tendencias UI modernas).
* **Performance 100/100:** Carga instantánea al no depender de librerías pesadas.
* **Mobile First:** Totalmente responsivo para celulares (donde están la mayoría de los clientes).
* **Integración de WhatsApp:** Botón flotante para contacto directo, vital para el mercado local.
* **Carrusel con Scroll-Snap:** Navegación fluida de proyectos destacados.
